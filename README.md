# Roomies

Roomies is a platform where people with a free room in a shared home can publish it, and
people looking for a place to live can find it, apply, visit, and move in. This
repository holds the group project, built incrementally across the course assignments.

## Group members

## Assignment 1 — contents

- **Landing page** — `index.html` and `styles.css`: the public homepage of Roomies,
  styled with Bootstrap. Open `index.html` in a browser to view it.
- **User stories** — `docs/user-stories.md`: the full set, for all three roles.
- **Domain model** — `docs/domain-model.md` (DBML and relationships) plus
  `docs/domain-model.png` (the diagram exported from dbdiagram.io).
- **Design decisions** — `docs/design-decisions.md`.

## Viewing the landing page

Open `index.html` in any modern browser. It loads Bootstrap 5 from a CDN, so an internet
connection is needed for the styles to render.

Later assignments turn this into a Ruby on Rails application; setup and run instructions
will be added to this README as the project grows.
