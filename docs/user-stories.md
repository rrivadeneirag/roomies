# Roomies — User Stories

Format: **As a [type of user], I want to [do something], so that [reason/benefit].**

Roomies has three roles: **Visitor** (not signed in), **Member** (acts as **host** on
their own listings and as **seeker** on everyone else's), and **Moderator**.

## Visitor (not signed in)

1. As a visitor, I want to browse the published listings without an account, so that I
   can explore what rooms are available before signing up.
2. As a visitor, I want to search listings by neighborhood, maximum rent, availability
   date, and amenities, so that I can narrow the results down to rooms that fit me.
3. As a visitor, I want to open a listing and see the room, its photos, description,
   rent, availability, and the property's amenities, so that I can judge whether the
   room suits me.
4. As a visitor, I want to read the reviews left by people who visited a property, so
   that I can trust what the listing promises.
5. As a visitor, I want to be asked to sign up or log in when I try to apply, save, or
   report, so that I understand those actions need an account.

## Member — as a host

6. As a host, I want to register a property with its address, neighborhood, property
   type, bedrooms, bathrooms, shared spaces, and amenities, so that seekers know the
   home a room belongs to.
7. As a host, I want to publish a listing for each available room — with its rent,
   deposit, availability date, minimum stay, whether it is furnished, whether it has a
   private bathroom, a rich description, and photos — so that seekers can evaluate and
   apply to the room.
8. As a host, I want to keep a listing as a draft until it is ready, so that only I can
   see it before it is published.
9. As a host, I want to keep several listings on one property over time, and more than
   one at once when two rooms are free, so that I can offer every available room.
10. As a host, I want to see the applications received on my listings, each with its
    message, move-in date, and intended stay, so that I can compare the interested
    seekers.
11. As a host, I want to shortlist an application, so that I signal I am interested and
    want to arrange a visit.
12. As a host, I want to propose a visit to a shortlisted applicant on a date and time,
    and cancel and propose another if needed, so that we can meet before deciding.
13. As a host, I want to accept exactly one application per listing, so that the chosen
    seeker gets the room, every other pending or shortlisted application is rejected,
    and the listing becomes reserved — all in one step.
14. As a host, I want to reject an application, so that I can discard an applicant who
    does not fit.
15. As a host, I want the listing to move to rented once the new housemate has moved
    in, so that the platform reflects that the room is taken.
16. As a host, I want to withdraw a listing, so that I can take it down when the room is
    no longer available.

## Member — as a seeker

17. As a seeker, I want to apply to a published listing with a message, my intended
    move-in date, and how long I intend to stay, so that the host can consider me.
18. As a seeker, I want to be stopped from applying twice to the same listing, to my own
    listing, or to a listing that is not published, so that my applications stay valid.
19. As a seeker, I want to withdraw my application, so that I can pull out when I am no
    longer interested.
20. As a seeker, I want to confirm a visit the host proposed, so that the meeting is
    scheduled.
21. As a seeker, I want to leave a review with a rating from 1 to 5 and a comment on
    whether the place matched, after a completed visit, so that future seekers can
    trust the listing.
22. As a seeker, I want to save listings, so that I can come back to them later.
23. As a seeker, I want to see only my own applications and their status, so that my
    applications stay private from other members.

## Member — reporting

24. As a member, I want to report a listing that looks fraudulent, misleading, or
    offensive, so that a moderator can review it and take action.

## Moderator

25. As a moderator, I want to review reported listings, so that I can decide whether
    they break the rules.
26. As a moderator, I want to take down a listing that violates the rules, so that the
    platform stays safe; taking it down voids its pending applications.
27. As a moderator, I want to manage the neighborhood catalog, so that hosts choose
    from a consistent set of neighborhoods.
28. As a moderator, I want to manage the amenity catalog, so that properties describe
    their amenities from a consistent set.
